Este documento reúne os mapeamentos essenciais para utilizar o AstroVim de forma produtiva.

---

## Geral
- **Leader key:** `<Space>`
- **Local Leader key:** `,`
- **Salvar arquivo (Force Write):** `Ctrl + s`
- **Fechar (Force Quit):** `Ctrl + q`
- **Novo arquivo:** `<Leader> + n`
- **Fechar buffer:** `<Leader> + c`

---

## Aba Lateral (Neo-Tree)
- **Abrir aba lateral:** `<Leader> + e`
- **Focar aba lateral:** `<Leader> + o`

---

## Navegação entre Janelas
- **Mover entre janelas:**
  - Cima: `Ctrl + k`
  - Baixo: `Ctrl + j`
  - Esquerda: `Ctrl + h`
  - Direita: `Ctrl + l`

---

## Buffers
- **Próximo buffer:** `]b`
- **Buffer anterior:** `[b`

---

## LSP (Language Server Protocol)
- **Hover (ver documentação):** `K`
- **Formatação do documento:** `<Leader> + lf`
- **Ir para definição:** `gd`
- **Renomear símbolo:** `<Leader> + lr`
- **Ações de código:** `<Leader> + la`

---

## Pesquisa (Picker)
- **Buscar arquivos:** `<Leader> + ff`
- **Live Grep:** `<Leader> + fw`

---

## Terminal
- **Abrir terminal flutuante:** `<Leader> + tf`
