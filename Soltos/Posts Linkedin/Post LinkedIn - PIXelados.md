
"Quem nunca passou por aquela discussão infinita de contas compartilhadas em repúblicas? 💸 Decidi resolver esse problema de uma vez por todas!"

Depois de meses convivendo com aquelas planilhas confusas e mensagens perdidas no grupo do WhatsApp sobre quem pagou o quê, decidi criar uma solução que realmente funciona.

Apresento o PIXelados, uma aplicação web que estou desenvolvendo para acabar com as dores de cabeça na gestão financeira de moradias compartilhadas! 🏠

💡 O PIXelados nasceu de uma necessidade real: simplificar a vida financeira de quem divide casa.

Como funciona? • Registre suas despesas em segundos • A aplicação divide automaticamente os valores • Cada morador vê exatamente quanto deve • Compartilhe novas despesas via link • Visualize as chaves Pix de cada usuário para pagamentos rápidos

O melhor? Tudo isso em uma interface limpa e intuitiva, sem complicações! 😉

🛠️ Tecnicamente, estou construindo com: • Next.js + TypeScript para uma experiência fluida • PostgreSQL + Prisma para um banco de dados robusto • Tailwind CSS para um design moderno • NextAuth.js para segurança nas autenticações

O projeto está em desenvolvimento e já pode ser acessado em versão beta. Estou realmente empolgado com o potencial de resolver um problema tão comum!
